1. Open this folder in VS Code.
2. Open Terminal 1:
   cd backend
   npm install --no-audit --no-fund
   node server.js
3. Open Terminal 2:
   cd frontend
   npm install --no-audit --no-fund
   npm run dev
4. Open http://localhost:3000
5. If an old server is running, stop it first:
   Windows CMD: taskkill /F /IM node.exe

SIH26103 AUTHENTICATION / ROLE UPDATE
====================================
- General User: register/login and view/search the portal, map, routes, projects, reports and alerts.
- Administrator: generate an administrator key on first setup, register/login with email + password + key, then manage project data.
- Administrator key is generated by the backend and stored only as a salted hash in infra_risk_auth.json. It is not hard-coded in frontend JavaScript.
- Every project add/edit/delete and verified-GIS import requires an authenticated administrator session and a fresh administrator-key authorization.
- Alert acknowledgement is administrator-only and is persisted with acknowledgement time/user in infra_risk_data.json.
- Reports > Time Delay calculates planned duration, actual/expected duration, delay days and delay percentage from project dates.
- Route analysis no longer generates DEMO/SIMULATED projects. If live/verified sources return no route projects, the result remains empty and the UI explains that no source-backed project was found.
- On first run, open the login page, choose Administrator, click Generate, save the displayed key securely, then register the first Administrator account with that key.
